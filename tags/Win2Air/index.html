Win2Air：把 Windows 系统声音投送到 HomePod
2026年10月25日 643 字 大概 2 分钟 软件 AirPlay HomePod Win2Air Windows

用免费、开源的 Win2Air 连接 HomePod，就能把 Windows 正在播放的声音传过去。听歌、看视频，继续用原来的播放器或浏览器就行。

除了 HomePod，也能连接开启了 AirPlay 接收功能的 Mac，以及其他兼容 AirPlay 的音频设备。

获取方式：从 Microsoft Store 安装 Win2Air。
